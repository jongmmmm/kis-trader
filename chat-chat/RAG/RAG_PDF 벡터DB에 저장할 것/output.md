세무정보(소득, 납세 내역 등)는 개인정보보호법상 명시된 민감정보(건강, 정치, 성적 지향 등)에는 해당하지 않습니다. 그러나 금융정보와 결합 시 사실상 민감정보에 준하는 보호가 필요합니다. 삼쩜삼은 "납세자의 과도한 개인정보 수집으로 개인정보보호법 위반 소지"가 있다는 지적을 받았습니다.

# 3. RAG 기술 활용 핵심 전략

# ① 세법 실시간 업데이트 RAG

일반 LLM 의 가장 큰 약점인 세법 개정 미반영 문제를 정면 돌파

- •국세청 법령정보, 기재부 세제 고시, 대법원 판례 자동 크롤링
- •변경 감지 시 벡터 DB 자동 업데이트 파이프라인 구축
- •항상 최신 세법 기준으로 답변 — 경쟁사 불가능한 핵심 차별화

# ② 개인 맞춤형 Context RAG

사용자 프로필을 RAG 필터 조건으로 활용해 정확도 극대화

- •업종 코드, 사업자 유형, 연 매출 규모, 주요 비용 항목 등록
- •해당 프로필에 맞는 문서만 선별 검색 → 관련성 높은 답변 생성
- •"나한테 맞는 답변"이 핵심 차별화 포인트

# ③ 커뮤니티 공유형 RAG ("같이 쓰는" 구현)

익명화된 유사 사례를 데이터 자산으로 축적하여 네트워크 효과 창출

- •익명화 기준: 금액 범위 표시, 업종 대분류, 개인정보 완전 제거
- •"비슷한 상황의 사업자 500 명은 이렇게 했어요" 형태로 제공
- •사용자 많을수록 품질 향상 — 경쟁사 복제 불가 데이터 자산 구축

| ✗ 더존은 비싸다    | ✓ 우리는 저렴하다 (월 9,900 원)    |
| ------------ | ------------------------- |
